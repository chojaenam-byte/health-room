# v2 — 재작성본 (테스트)

운영 중인 `main` 은 건드리지 않았다. 이 폴더는 **별도 배포**로만 돈다.

## 왜 다시 썼나

v1은 키오스크가 `getStudents` 로 **전교생 명단을 통째로 받아** 브라우저에서 학번을 대조했다.
그래서 그 액션이 인증 없이 열려 있어야 했고, 주소만 알면 누구나 다음을 받을 수 있었다
(2026-08-28 확인, 응답 크기만 측정하고 내용은 열람하지 않음):

| 호출 | 응답 |
|---|---|
| `getStudents` | 200 · 23KB — 전교생 이름+학번 |
| `getLogs` | 200 · 219KB — 방문·처치 기록 |
| `getQueue` | 200 · 453B |

저장소가 public 이고 GitHub Pages 로 서비스 중이라 `/exec` 주소도 소스에 그대로 있었다.

## 무엇이 달라졌나

| | v1 | v2 |
|---|---|---|
| 학번 확인 | 명단 전체를 받아 브라우저에서 대조 | `lookupStudent` 로 **그 한 명만** |
| 키오스크 인증 | 없음 | 기기 토큰(1대). 소스에 없고 등록 시 발급 |
| 교사 화면 | 누구나 열람 | 비밀번호 필수 |
| 인증 없는 액션 | 전부 | **없음** (`provisionKiosk` 만 비밀번호로 검사) |
| 순서 변경 | 전부 지우고 재삽입 — 실패 시 대기열 유실 | `ts` 값만 재부여, 행을 지우지 않음 |
| 동시성 | 없음 | 모든 쓰기를 `LockService` 로 감쌈 |
| 이름 출처 | 클라이언트가 보낸 값을 신뢰 | 서버가 시트에서 다시 읽음 |
| 학생 화면의 비고 | — | 응답에 아예 넣지 않음(알레르기 등 노출 방지) |
| `eval()` | onclick 문자열을 eval | `data-k` 속성 + 매핑 테이블 |
| 엑셀 CDN | 실패 시 업로드 불가 | 실패 감지 후 CSV 로 안내 |
| OAuth 스코프 | 자동 추론 | `appsscript.json` 에 **명시** (스코프가 바뀌어 트리거가 죽는 사고 예방) |

## 파일

- `Code.gs` — 백엔드. 액션 18개, 권한 3단계(kiosk / teacher / none)
- `student.html` — 키오스크
- `teacher.html` — 교사 화면
- `appsscript.json` — 스코프·웹앱 설정

## 켜는 법 (처음 한 번)

1. 편집기를 연다: `clasp open-script` 또는 스크립트 주소
2. 함수 목록에서 **`setup`** 을 골라 **▶ 실행**
   - 구글이 권한을 물어본다 → 허용 (에이전트가 대신 못 하는 유일한 단계)
   - 실행 로그에 **전용 시트 주소**와 **교사 비밀번호**가 찍힌다
3. (선택) **`seedTestStudents`** 실행 — 가짜 학생 5명. **실제 명단을 테스트 시트에 넣지 않기 위한 것**
4. `student.html` 을 열고 교사 비밀번호를 한 번 입력 → 기기 등록 완료
5. `teacher.html` 은 같은 비밀번호로 로그인

비밀번호 변경: 프로젝트 설정 → 스크립트 속성 → `TEACHER_PW`
키오스크 교체: 편집기에서 `rotateKioskToken()` 실행 후 새 기기에서 재등록

## 아직 남은 것

- **운영 전환 전 시트 스키마 대조** — v2는 자기 시트를 새로 만든다. 운영 시트로 갈아탈 때
  컬럼 순서가 v1과 같은지 확인해야 한다. v1 백엔드 소스가 저장소에 없어 아직 대조하지 못했다.
- JSONP라서 토큰이 URL 쿼리에 실린다. GAS 실행 로그에 남는다. 정적 호스팅에서 CORS 없이
  부르려면 이 방법뿐이라 감수한 선택이다.
- 학번이 4자리(약 2,700개)라 단일 조회도 전수 대입이 가능하다. 그래서 기기 토큰을 붙였다.
